# 第8周综合展示讲稿

1. 项目背景：我叫彭文玥，项目把儿童故事从文字扩展到图像、音频和视频。
2. 现场操作：打开网页，输入主角、年龄、兴趣，切换三个主题；运行生成脚本查看 JSON、配图、音频、字幕和视频。
3. 技术亮点：结构化 JSON 校验、固定 seed 角色一致性、Edge TTS 多音色、轻量向量检索、Agent 五步规划。
4. 工程决策：免费服务优先，缓存与离线降级保证演示连续性；API key 只放 `.env`。
5. AI协作：AI 负责代码草稿、Prompt 分析和文档初稿，我负责字段核验、媒体检查、结果筛选和最终组装。
6. 反思：多模态产品的难点来自跨模态一致性、API可靠性、成本和评估，下一步接入真实 CLIP 权重与更精细的时间轴。
