# 技术验证

验证目标：确认结构化故事、免费生图、免费语音和本地视频可以串联。

| 验证项 | 方法 | 结果 |
|---|---|---|
| JSON | 调用 `validate_story` | 字段完整 |
| 生图 | 调用 Pollinations，保存 seed | 生成3幕 |
| 语音 | 调用 Edge TTS，保存4路音频 | 角色音色分离 |
| 视频 | imageio-ffmpeg 合成图片与音频 | 输出 MP4+SRT |
| Agent | 两个创意、两次干预 | 生成两份流程日志 |

采用结论：轻量免费服务适合课程演示；部署环境保留接口切换点和离线缓存。
