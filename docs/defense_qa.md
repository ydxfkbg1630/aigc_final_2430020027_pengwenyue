# 答辩问答

**为什么选择固定 seed？**

固定 seed 配合稳定角色锚点，让不同场景中发型、发夹、外套、背包和画风保持一致，便于人工对比。

**API 失败时怎么演示？**

代码将网络调用、缓存和离线降级统一封装，演示目录保留已生成的 JSON、图片、音频和视频。

**RAG 与普通关键词筛选有什么差别？**

系统把查询与素材文本转为向量并用余弦相似度排序，输出 Top-K 与结构化建议；评估表记录三个自然语言查询。

**Agent 的自主性如何体现？**

Agent 先形成步骤计划，再调用素材、写作、图像、TTS、剪辑工具，并把用户干预写入日志后重新执行。

**AI 生成和人工工作如何区分？**

AI 生成代码草稿、Prompt 初稿和文档骨架；人工确认 API 参数、修正字段、核对媒体、筛选成品并完成最终报告。
