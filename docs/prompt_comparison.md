# Prompt策略对比报告

同一组输入分别采用 zero-shot、few-shot、role-playing 三种策略，程序自动生成 JSON 并保留相同字段。结果见 `prompt_strategy_comparison.csv`。

| 策略 | 结构完整 | 细节 | 人工评分 |
|---|---|---|---:|
| 零样本 | 是 | 叙事简洁 | 3.8 |
| 少样本 | 是 | 场景细节更丰富 | 4.3 |
| 角色扮演 | 是 | 角色动机与儿童表达更自然 | 4.7 |

结论：角色扮演策略作为默认策略，少样本策略作为质量对照，零样本策略作为低成本基线。程序对三种策略统一执行 JSON 字段校验。
