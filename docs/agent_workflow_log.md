# Agent创作流程日志

## 案例1

- 输入：月光森林里，一封星光信件寻找勇气。
- 干预：把主角设定为女孩，保留森林场景。
- 规划：检索素材 → 生成结构化故事 → 生成3张配图 → 生成4路音频 → 合成视频。
- 输出：`outputs/agent_runs/case_01.json`。
