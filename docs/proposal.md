# proposal.md

## 项目基本信息

- 项目：故事星球多模态儿童故事工坊
- 作者：彭文玥
- 学号：2430020027
- 目标：让儿童故事从一次文字生成扩展为可阅读、可听、可观看的多模态产品。

## 用户与需求

目标用户为7至12岁儿童及家长。用户可以输入主角、年龄、兴趣、场景、主题和故事长度，获得结构化故事、配图、有声朗读、字幕视频和素材推荐。

## 核心功能优先级

P0：结构化故事、三主题网页、场景配图、TTS、视频合成。
P1：素材库向量检索、角色一致性、同步高亮文本。
P2：Agent规划、用户干预、评估报告和现场演示模式。

## 用户故事

- 作为儿童，我希望输入兴趣后看到属于自己的故事，并切换不同主题。
- 作为家长，我希望故事可以朗读并导出视频，方便陪伴阅读。

## 非功能需求

配置安全、接口缓存、错误重试、离线降级、结构化日志、可复现目录和生成结果保留。

## 技术方案

Python 3.12、OpenAI兼容文本接口、Pollinations免费生图、Edge TTS、imageio-ffmpeg、轻量向量检索、Agent工具编排。

## 进度

第1周网页，第2周JSON，第3周配图，第4周音频，第5周视频，第6周检索，第7周Agent，第8周综合展示；后半阶段补充提案、验证、中期、测试、部署和总结文档。
